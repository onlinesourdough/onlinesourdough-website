# Local menu animation assets

The Codex sheet is an unchanged copy of the same original OpenAI companion used
in Arc’IT Factory: https://persistent.oaistatic.com/codex/pets/v1/codex-spritesheet-v4.webp.
The 192 × 208 frames are selected at runtime; rows 0 and 7 supply idle/blink and
laptop work. The CDN mascot has no independently established redistribution
licence here; production reuse remains a release-review item, as for Factory.

Claude uses the same segmented MIT Lobe Icons silhouette as Arc’IT Factory:
https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons/claudecode-color.svg.
The accompanying LobeIcons-LICENSE.txt is retained. Stirring and blinking are
original illustrative motion, not claimed to be an official Anthropic animation.

The original four menu PNGs remain unchanged. Orange tile colours come from the
Gustav Online contribution field and LinkedIn banner. They are decorative, not
measured activity. The small starter jar is original SVG geometry using the
existing scene's palette. All motion respects visibility and reduced motion.
