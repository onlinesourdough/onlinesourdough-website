Source: https://raw.githubusercontent.com/lobehub/lobe-icons/master/packages/static-svg/icons/notion.svg

The mark illustrates a context home in the bread scene; it does not represent a live connection or partnership. OSM is The Onlinesourdough Method, not OpenStreetMap. The scene performs no API requests.
